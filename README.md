# IBM Data Science Professional Certificate

---

## Featured Work

### [Applied Data Science Capstone — SpaceX Launch Prediction](./Capstone)
End-to-end data science project predicting Falcon 9 first-stage landing success. Covers REST API data collection, web scraping, SQL-based EDA, geospatial analysis with Folium, and classification modeling (Logistic Regression, SVM, Decision Tree, KNN). Built to answer a real business question: can a competitor accurately estimate SpaceX launch costs based on landing probability?

---

## Overview

This repository documents completion of the **IBM Data Science Professional Certificate** on Coursera — a 12-course, industry-recognized program covering end-to-end data science using Python, SQL, machine learning, data visualization, and real-world analytics workflows.
